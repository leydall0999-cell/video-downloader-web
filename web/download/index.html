macOS

DMG · 296 MB · macOS 11+（Intel / Apple Silicon 通用版）。

下载 macOS

安装：打开下载的 DMG，把「视频工坊」拖进「应用程序」文件夹。首次打开若提示无法验证，请右键点按图标再选「打开」（仅需一次）。

打不开 DMG？下载 ZIP 版（270 MB，解压后同样拖进「应用程序」）

点了没反应？改用直连地址下载（同一个文件，不经过本站跳转）。

下载太慢？点这里提速
安装包由 Cloudflare 全球边缘分发，支持断点续传。网络不佳时用多线程下载工具通常能快 2–4 倍：

· aria2（命令行）：先 brew install aria2，再运行 aria2c -x16 -s16 "https://hanyuxz.top/download/installer?p=macos"

· FDM / Motrix（免费图形工具）：新建任务，粘贴本页「下载」按钮的链接即可

Windows 版正式上线

视频工坊现已提供 Windows 安装包，功能与 Mac 版一致；双击安装，一路「下一步」即可，无需另装 Python、无需配置环境。

Windows 版能做什么

  • 视频下载：粘贴链接即可解析，支持多档清晰度、批量下载与断点续传
  • 一键解说：导入视频自动生成解说文案 + 配音 + 字幕，直接出成片（已内置在安装包里）
  • AI 去水印 / 智能抠图：图片去水印、一键抠图换背景
  • 字幕提取：本地视频 / 音频转字幕
  • 视频压缩、格式转换等常用工具

更新内容

  • 新增解析平台「金牌影院」（nmwchxx.com）：粘贴播放页链接即可解析，自动识别片名与集数，支持蓝光 / 高清 / 标清三档清晰度
  • 修复：视频压缩的「质量」选项此前不起作用——选哪一档压出来的大小和画质都一样。现已接上，并把档位改成「更清晰 / 均衡 / 更小」三档，各自对应不同画质与体积；默认档与原来一致
  • 修复：少数任务操作（取消、暂停等）在已登录状态下会被误判为「需要登录」而拦下
  • 修复：对账时部分历史订单被误报成「已付款未发放」，实际早已发放，不会再误报
  • 后台新增「风险复核队列」：自动标记异常账号行为（频繁换设备、一台设备登录多个账号、卡密连续试错等）并按风险分排序，供人工复核；只提示、不会自动限制任何账号
  • Windows 版支持应用内更新：「关于本应用 → 检查更新」即可自动下载并静默升级，不用再回官网重新下载覆盖安装（Mac 版原有能力，本次 Windows 补齐；安装包与任务数据不受影响）

安装提示：首次运行安装包，Windows SmartScreen 可能弹出「Windows 已保护你的电脑」（因尚未办理代码签名证书）。点「更多信息 → 仍要运行」即可继续安装，不影响使用。

安装包由 Cloudflare 全球边缘网络分发，下载即最新版；后续版本可在客户端内「检查更新」一键升级（Mac 为增量补丁通常只有几 MB，Windows 自动下载完整安装包静默升级）。安装包已不含语音识别模型——首次使用本地字幕/识别功能时会自动下载该模型（146 MB，同样走全速边缘，有进度显示，可跳过不用）。
